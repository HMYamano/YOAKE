# YOAKE Annotation Tool — 使い方ガイド

GUIベースの動画アノテーションツールです。動画ファイルを入力として、YOAKEが要求するJSON v1.1形式のデータセットを作成します。

## 1. インストール

```bash
# リポジトリのルートで実行
pip install -e ".[annotate]"

# または個別にインストール
pip install dearpygui opencv-python
```

---

## 2. 起動方法

```bash
# 通常起動（プロジェクト設定画面から開始）
python tools/annotate.py

# 動画ファイルを直接指定して起動
python tools/annotate.py path/to/video.mp4

# 既存アノテーションを読み込んで続きから作業
python tools/annotate.py path/to/video.mp4 --load path/to/annotations.json

# パッケージインストール済みの場合
annotate path/to/video.mp4
```

## 3. プロジェクト設定

起動すると最初に **プロジェクト設定画面** が表示されます。

![setup screen](../docs/images/setup_screen.png)

### 新規プロジェクトの場合

| 項目 | 説明 | 例 |
|------|------|----|
| **Project name** | プロジェクト識別名 | `courtship_exp_01` |
| **Class labels** | 検出対象のクラス名（カンマ区切り） | `fly` |
| **Action labels** | 行動ラベル（カンマ区切り、順番が`action_id`に対応） | `stationary, walking, grooming, courtship, aggression` |

入力後、**Create Project** ボタンを押すとメイン画面に移行します。

> **注意:** アクションラベルの順番が `action_id` の番号（0, 1, 2, ...）に対応します。後から順番は変更できないので、最初に確定させてください。

### 既存プロジェクトの再開

**Load Existing Annotation JSON…** を押すとファイル選択ダイアログが開きます。JSONを選択すると、クラス名・アクション名・アノテーション済みデータを自動で復元します。

```
│  │                                      │  │                          │ │
│  │  動画フレーム                         │  │  Active Track            │ │
│  │                                      │  │  ├ Track ID入力           │ │
│  │  ┌T1|walking──┐                      │  │  └ +New ボタン            │ │
│  │  │            │ ← バウンディングボックス│  │                          │ │
│  │  └────────────┘                      │  │  Objects in Frame        │ │
│  │                                      │  │  └ フレーム内の個体リスト   │ │
│  │  ● = トラッカー稼働中                 │  │                          │ │
│  │                                      │  │  Selected Box            │ │

│                                            │  └ Occluded / Is Crowd    │ │
│  ┌─ ナビゲーションバー ───────────────────┐  │                          │ │
│  │ |◀  ◀  [150] / 300  ▶  ▶|  Propagate│  │  Quick Actions (0–4)     │ │
│  │ ████████░░░░░░  50%  status message  │  │                          │ │

│                                            │  Labels / Frame Info     │ │
└────────────────────────────────────────────┴──────────────────────────┘
```

### Canvas（左側）

動画フレームが表示されます。バウンディングボックスの描画・選択・移動・リサイズをここで行います。

### Sidebar（右側）

| セクション | 内容 |
|-----------|------|
| **Active Track** | 新しく描くボックスに割り当てるトラックID |
| **Objects in Frame** | 現在フレームのアノテーション一覧。クリックで選択 |
| **Selected Box** | 選択中ボックスのTrack ID・Action・フラグを編集 |
| **Quick Actions** | ボタンまたはキー `0`〜`4` でアクションを素早く設定 |
| **Auto-Track** | 自動トラッキングモードのON/OFF・トラッカー管理 |
| **Labels** | クラス・アクションラベルの確認と追加 |
| **Frame Info** | 現在フレーム・アノテーション済みフレーム数などの統計 |

### ナビゲーションバー（下部）

- フレーム番号入力・前後移動ボタン
- **Propagate** ボタン：前フレームのボックスを現在フレームへコピー
- プログレスバー：アノテーション済みフレームの割合
- ステータステキスト

## 5. 基本的なアノテーション手順

### ステップ1: 動画を開く

`File → Open Video…` を選択して動画ファイルを開きます（MP4, AVI, MOV, MKV, WebM, M4V に対応）。

### ステップ2: トラックIDを設定する

Sidebar の **Active Track** セクションで、次に描くボックスのトラックIDを確認・変更します。

- **+New** ボタン：次の空きIDに自動インクリメント
- 数値入力欄に直接入力することも可能

各トラックIDは固有の色で表示されます（最大20色のパレットをループ）。

### ステップ3: バウンディングボックスを描く

Canvas の空き領域を **左ドラッグ** すると新しいボックスが描かれます。

- ドラッグ中：白破線のゴムバンド表示
- ドラッグ終了：Active Track IDのボックスが作成され、自動的に選択状態になる

### ステップ4: アクションラベルを付ける

ボックスが選択された状態で：

- キー **`0`〜`4`** を押す（最速）
- Quick Actions セクションのボタンをクリック
- Selected Box の Action ドロップダウンで選択

### ステップ5: ボックスを調整する

| 操作 | 方法 |
|------|------|
| **移動** | ボックス内をドラッグ |
| **リサイズ** | 選択中ボックスの4隅の白丸ハンドルをドラッグ |
| **選択** | ボックスをクリック |
| **選択解除** | `Escape` キー |
| **削除** | `Delete` キー（選択中のボックスを削除） |

### ステップ6: 次フレームへ進む

- `→` キーまたは `▶` ボタン
- 複数の個体が毎フレームほぼ同じ位置にいる場合は **Propagate** が有効

#### Propagate（前フレームからの伝播）

`Space` キーまたは **Propagate** ボタンで、前フレームのボックスを現在フレームにコピーします。同一トラックIDのボックスがすでに存在する場合はスキップされます。

流れ：
1. フレーム0で全個体のボックスを描く
2. フレーム1に移動し `Space` を押す → 全ボックスがコピーされる
3. 位置を微調整
4. 以降繰り返し

### ステップ7: 保存する

`Ctrl+S` または `File → Save` でJSONファイルを保存します。

## 6. 自動トラッキングモード

**OpenCV CSRT トラッカー**を使って、ボックスの位置を後続フレームへ自動的に追従させるモードです。

### 有効化

- `A` キー
- Sidebar の **Auto-Track** セクションのチェックボックス

チェックボックスがONになると **Auto-track mode: ON** とステータスバーに表示されます。

### 動作の流れ

```
1. Auto-track ON の状態でボックスを描く
         ↓
2. CSRT トラッカーが自動で初期化される（緑ドットが点灯）
         ↓
3. → キーで次フレームへ進む
         ↓
4. 全アクティブトラッカーが自動でボックス位置を検出・更新
         ↓
5. 必要に応じてボックスを手動で微調整（調整後は自動でトラッカー再初期化）
```

### トラッカーの状態表示

- ボックス左下の **緑ドット（●）** = トラッカーが稼働中
- 緑ドットなし = トラッカー未初期化

### トラッカー操作

| 操作 | 方法 |
|------|------|
| 選択中ボックスのトラッカーを手動初期化 | 右クリック → **Init Tracker for This Box** |
| 選択中ボックスのトラッカーを削除 | 右クリック → **Remove Tracker for This Track** |
| 全トラッカーをリセット | Sidebar **Reset All Trackers** ボタン |
| 選択中トラッカーのみリセット | Sidebar **Reset Selected Tracker** ボタン |

### 注意事項

- CSRTトラッカーは高精度ですが、**急激な動き・オクルージョン・個体同士の交差**で追跡失敗することがあります。追跡失敗時はステータスバーに `Tracker lost for T{id}` と表示されます。
- トラッカーは **1フレーム先送り**の際のみ自動更新されます（複数フレーム飛ばしには対応していません）。
- ボックスを手動で移動・リサイズした場合、新しい位置でトラッカーが自動再初期化されます。

## 7. ラベルの追加

アノテーション作業中にいつでもラベルを追加できます。

### クラスラベルの追加

`Labels → Add Class Label…` またはSidebar **Labels** セクションの **+ Add Class** ボタン。

### アクションラベルの追加

`Labels → Add Action Label…` またはSidebar **Labels** セクションの **+ Add Action** ボタン。

ダイアログに新しいラベル名を入力して **Add** を押すと：
- Quick Actions ボタンが更新される
- Selected Box の Action ドロップダウンに追加される
- 保存されるJSONの `action_names` に追記される

> **注意:** 追加したラベルは既存ラベルリストの**末尾**に追加されます。既存の`action_id`番号は変化しません。

## 8. ファイル操作

ファイル操作のダイアログはOSネイティブのダイアログ（tkinter）で表示されます。

| 操作 | メニュー | ショートカット |
|------|---------|--------------|
| 動画を開く | `File → Open Video…` | — |
| アノテーションを読み込む | `File → Load Annotation…` | — |
| アノテーションを保存 | `File → Save` | `Ctrl+S` |
| アノテーション保存 + フレーム画像書き出し | `File → Save & Export Frames…` | — |
| 新規プロジェクト | `File → New Project…` | — |

### Save & Export Frames

出力ディレクトリを選択すると以下が生成されます：

```
<出力ディレクトリ>/
├── annotations.json          ← YOAKE JSON v1.1
└── images/
    └── <video_stem>/
        ├── 000000.jpg        ← アノテーション済みフレームのみ
        ├── 000005.jpg
        └── ...
```

フレーム画像はJPEG品質95で書き出されます。

## 9. キーボードショートカット一覧

| キー | 動作 |
|------|------|
| `→` / `N` | 次フレームへ |
| `←` / `P` | 前フレームへ |
| `Space` | 前フレームからボックスを伝播 |
| `A` | 自動トラッキングモードON/OFF |
| `Delete` | 選択中ボックスを削除 |
| `0` | アクション0（stationary など）を設定 |
| `1` | アクション1（walking など）を設定 |
| `2` | アクション2（grooming など）を設定 |
| `3` | アクション3（courtship など）を設定 |
| `4` | アクション4（aggression など）を設定 |
| `Ctrl+S` | アノテーションを保存 |
| `Escape` | 選択解除 |

### マウス操作

| 操作 | 動作 |
|------|------|
| 空き領域を左ドラッグ | 新しいバウンディングボックスを描く |
| ボックスを左クリック | ボックスを選択 |
| 選択中ボックスをドラッグ | ボックスを移動 |
| 選択中ボックスの隅ハンドルをドラッグ | ボックスをリサイズ |
| ボックスを右クリック | コンテキストメニュー（トラックID設定・アクション設定・削除） |

## 10. 出力フォーマット

YOAKE JSON v1.1 形式で出力されます。

```json
{
  "meta": {
    "version": "1.1",
    "created": "2026-03-17T12:00:00",
    "fps_default": 25.0
  },
  "class_names": ["fly"],
  "action_names": ["stationary", "walking", "grooming", "courtship", "aggression"],
  "videos": [
    {
      "video_id": "experiment_01",
      "fps": 25.0,
      "width": 640,
      "height": 640,
      "num_frames": 300,
      "frames": [
        {
          "frame_index": 0,
          "image_path": "images/experiment_01/000000.jpg",
          "objects": [
            {
              "object_id": 1,
              "bbox": [120, 85, 175, 130],
              "class_id": 0,
              "track_id": 1,
              "action_id": 1,
              "occluded": false,
              "is_crowd": false
            }
          ]
        }
      ]
    }
  ]
}
```

### フィールド説明

| フィールド | 説明 |
|-----------|------|
| `bbox` | `[x1, y1, x2, y2]` ピクセル座標（左上・右下） |
| `track_id` | 動画内で個体を一意に識別するID。未設定の場合 `-1` |
| `action_id` | `action_names` のインデックス。未アノテーションの場合 `-1` |
| `occluded` | 部分的に隠れている場合 `true` |
| `is_crowd` | 複数個体が分離不可能な塊の場合 `true`（損失計算から除外） |

## 11. 推奨ワークフロー

### 省力化ワークフロー（自動トラッキング使用）

```
1. プロジェクト設定でラベルを定義
          ↓
2. 動画を開く
          ↓
3. Auto-Track を ON にする (A キー)
          ↓
4. フレーム0 で全個体のボックスを描く
   → 各個体に固有のTrack IDを割り当て
   → トラッカーが自動初期化（緑ドット点灯）
          ↓
5. → キーで次フレームへ
   → 全トラッカーが自動で位置を更新
          ↓
6. 必要に応じてボックスを微調整
   （ズレが大きい場合は手動で修正 → 自動再初期化）
          ↓
7. アクションラベルを付ける（キー 0〜4）
          ↓
8. 5〜7 を繰り返す
          ↓
9. Ctrl+S で保存
```

### 精密ワークフロー（手動伝播）

```
1. プロジェクト設定
          ↓
2. フレーム0 で全個体のボックスを描き、アクションを設定
          ↓
3. → キーで次フレームへ移動
          ↓
4. Space キーで前フレームのボックスを伝播
          ↓
5. 各ボックスを微調整し、アクションを更新
          ↓
6. 3〜5 を繰り返す
          ↓
7. Ctrl+S で保存
```

### データ品質の目安

| 項目 | 推奨 | 最低限 |
|------|------|--------|
| アノテーション密度 | 全フレーム（100%） | 5フレームに1フレーム以下は空白NG |
| トラック長 | 平均50フレーム以上 | 16フレーム以上（未満は時系列学習に不使用） |
| アクションラベル | 全フレーム設定 | 未設定は `-1` のままでOK |
| train/val/test 分割 | 70 / 15 / 15（動画単位で分割） | — |

詳細は [`docs/DATASET_FORMAT.md`](DATASET_FORMAT.md) を参照してください。
